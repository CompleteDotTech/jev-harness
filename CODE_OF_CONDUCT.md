# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be specific, be kind, assume good faith, and argue with evidence. Harassment, personal attacks, and publishing others' private information are not tolerated. Community project questions belong in this repository; official product, account, billing, and API-support questions belong with TypeSafe AI's official channels.

Reports go to the repository maintainers through GitHub. Maintainers will respond privately and may remove content or contributors who violate this standard.
